# Ask SoldBench AI 实施规格

2026-11-25，用户确认原型右下角的 Ask SoldBench AI 是需纳入交付计划的产品功能。[HTML 原型](<../SoldBench Prototype.html>) 的 `askPill`／`askPanel` 在账户 Overview 等页面提供浮动入口，面板说明正式产品应回答文档、接入设置和产品问题。原型的五项链接定义推荐问题和交互位置，完整体验按 DEC-19 实施。当前应用尚未挂载该入口或问答能力。[页面规格](功能与页面规格.md) · [开发台账](开发排期与任务台账.md)

## 1. 首发产品问答（TASK-063）

| 用户动作 | 必须交付 |
|---|---|
| 打开／关闭 | 公开站与账户中心共用一个原型浮动入口，保持右下角位置、紧凑桌面版和移动版。面板可键盘打开，通过 Escape 关闭并恢复焦点。切语言、切页面和打开链接不能阻断原工作流；窄屏不遮挡查价或领取操作。 |
| 点击推荐问题 | 首次 API 请求、每次查询最多 1 credit 的适用条件、中位数计算、连接 Agent、系统状态五项完整保留。点击显示本语言简要答复、相关小节和操作入口。连接示例只展示已核验的文档或明确标注的配置说明，状态不可用时显示未知或跳到可信状态页。 |
| 自己提问 | 提供可输入中英文问题的表单，以自然语言和同义词命中发布过的 FAQ、帮助问答、Quickstart、认证及接入说明、定价计量规则、方法与公开状态。复用现有双语文档索引和内容发布流程，服务端按词条和别名归一匹配，返回已审核的答复或受控摘录、标题、章节链接和内容版本。问题有歧义时显示相关问题让用户选择。 |
| 等待、失败与求助 | 有提交中、空输入、未命中、暂不可用、限流与重试态。没有依据时说明未找到可靠答案，给出文档搜索及支持出口。保持原页面筛选与输入。首发上线的本地知识问答模式在界面明示；生成式模式依专项验收。 |
| 查找个人结果或问产品估值 | 可引导到本人账户、用量、订单、研究和已批准的状态入口。面板只消费获准公开知识，页面上下文最多传页面类型、语言和已公开主题，不携带 owner、查询/订单、卖家或支持详情。对账户余额、某件商品成交价等请求，回到相应业务页依既有权限和显式领取流程处理。 |

答复必须来自当前生效内容。运营可维护英中推荐问题、别名、审定答复、来源链接及显隐，复用 TASK-057 的草稿、审核、发布和撤回。文档构建、内容发布或撤回时更新公开索引，已撤下内容不能由旧索引返回。定价、统计与状态中的事实引用相应的当前权威说明，编辑答复不能改变业务规则。不要把原型的 1 credit 标题变成排队、失败、低样本、陈旧或免费复取必扣的规则。

请求校验问题长度、频率和同源入口。匿名者可用公共答复。用户不得输入 API key、付款凭证或验证信息，服务端不持久化问题原文、凭证或私人上下文。诊断记录最小必要的响应分类、内容版本、语言与脱敏请求标识。全部产品问答动作对查价为 0 credit，无查询创建、扣费或领域写操作。运行失败可独立关闭问答，直接提供已核实帮助链接，保留查价和账户功能。

## 2. 生成式问答专项（TASK-064）

本任务单列 12 人日候选工程，前置是 TASK-063 的可信知识层和产品负责人对服务形态、费用上限、数据处理及公开范围的确认。供应商、模型、额度数字、是否收费及流量开放方案未选定。可评审本地/自托管模型、受批准的托管模型及维持本地知识问答。待审批期间，首发可独立交付上一节。

- 只检索审核通过、当前可见的帮助内容。回答附可访问出处、文档版本与语言；证据薄弱或互相冲突时回退本地结果，保留支持入口。首发知识边界不扩至私有成交、凭据、个人账单、工单和内部文档。
- 从产品事实与账务说明提取不可更改的字段。任何价格、样本和账户数字均须有当前、获准的依据；报价、统计和实际扣费由现有服务决定。用户问题、检索返回的文字及链接均作为数据，不能触发工具执行、源访问、领取或后台写命令。
- 对批准后的模型入口设独立预算、频控、并发、超时和停用开关，模型临时不可用降级到 TASK-063。外部联调只用经批准的内容、凭证和环境。保留最少的使用、费用与失败数据，留存和脱敏按签收后规则实施。
- 通过 AT-083 的证据、两语效果、不可证问题拒答、撤下失效、权限隔离、模型不可用及费用上限测试。原型文档链接和 MCP 的存在均须按各自功能验收。

## 3. 交接与验收

首发 5 人日估算由知识检索和内容配置 2、原型交互 2、双语与回归 1 组成。先用可审定的知识条目跑通离线问答。AT-082 随 G4 独立复核，覆盖空浏览器、登录账户、推荐问题、自行输入、来源打开、状态失败、切语言、键盘、320/390/768/1440 px、撤回内容即时拒读和查价账本零变化。TASK-064 另验模型响应和费用，结果写台账，外部批准单独留证。
