# 匿名缓存与受控分享

ADR-12、DEC-05/08 及 TASK-031/036 的本机实施。用户或访客只能访问当前权利允许的冻结权威统计，不重算、不消费credit、不启动抓取或查询Worker。

- 分享须本人有效会话，写入同源/CSRF及10分钟近期认证，若已开启MFA同时校验近期MFA。仅已交付查询可创建，默认24小时、最长7天且受当前保留与许可到期约束。必须传幂等键；原始token只在首次返回。列表不返回token，撤销立即生效。公共读取时每次复验当前用户、快照来源与证据保留，隐藏或无效统一410。链接、摘要与错误均不得索引。首个离线公开字段级仅聚合统计和质量，不开放逐条、主图、来源ID、owner、费用或关键词。
- 来源必须分别显式许可 `permitted_fields.public_share=["aggregate"]` 与 `permitted_fields.public_cache=["aggregate"]`。没有这两个值时，各入口分别拒绝。已保存或登录可读的快照并不自动成为公开数据。撤销即使原链接或映射仍存在也立即拒读。
- 匿名只读管理侧显式发布的本机合成快照，规范query身份与REST一致。只提供当前24小时内的获准缓存，未命中返回明确恢复提示。第一方随机cookie与网络对端分别使用当日HMAC预算；忽略来源可伪造的转发头。每UTC日最多5次成功新交付，每分钟另限20次尝试。10分钟内同cookie/对端/参数/快照复用不二次计数，失败或未命中不扣日次数。计数和复用事实在同一事务中完成。

浏览器访问 `/share/:token` 时以 `Accept: text/html` 查看双语历史摘要。显式 JSON 请求保持原公开投影。`?lang=zh-CN` 仅变更界面语言，继续从同一权限守卫读取。浏览器在失权、过期或撤销时显示统一的不可用页并返回 410。研究工作台对已交付权威摘要提供显式创建和撤销操作。页面保留 `no-referrer`、`no-store` 与搜索引擎隔离。


本机 `PUBLIC_FIXTURE_AGGREGATES=true npm run developer:demo` 为新建合成源显式设置两权限。完成并领取的查询可以用本机 `npm run public:fixture -- publish <query_id>` 发布匿名缓存。脚本只允许本机PG，在发布和读取时都复查来源、版本和权利。公开空结果或低样本按冻结统计输出，不用模拟数据掩盖未命中。Bearer老调用保留用户查询原行为，公开流量只按匿名策略。

Worker每60秒分批清理超过约2个UTC日的匿名哈希/额度事实及旧速率桶；永久记录不保存原始访客cookie、IP、分享token或关键词。反向代理在真实发布前必须按可信网络边界取对端并验证访问日志不记录分享token。当前读取直接socket，不接受客户端自报Forwarded或X-Forwarded-For。光凭本机HTTP/PG测试不能签G4。
