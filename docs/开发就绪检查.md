## 3. 必须靠实测补齐的事实

1. **来源可持续性**：获准入口、真实字段能力、actual价与独立成交事件可得性、连续14天和生产型7天运行；没有这些证据仍不能保证“eBay数据稳定”。
2. **类目质量**：评级卡牌等实际金标和Precision/Recall/误差，不能用GameBoy合成数据代替。
3. **商业输入**：真实用户需求、完整成本、收款产品审核、正式价格/退款条款、域名注册/DNS、邮件与运维联系人。
4. **实现验收**：正式迁移/历史升级、100并发计费、真实浏览器、MCP双客户端、真实断源与恢复、授权小额交易、独立评审。

这些是台账中的明确交付任务，不是交给开发者猜的规则空白。任何一项未完成都不能在发布记录里写PASS；静态检查只签收其覆盖的文档/合成契约范围。
