## 2. 估算口径

假设一条全职工程实施线，每周5有效工作日，创始人/数据审核/专业方在关口配合；估算包含实现者单测和联调，不假设Agent可全天无等待完成所有工作。E日是人力顺序窗口，不是自然日或承诺日期。以下基准共 **156人日（31.2工作周）**，另预留20%向上取整 **32人日**，合计约 **188人日/37.6工作周**，不含外部许可/支付审核等待及无法被其他工作覆盖的连续观察时间。

第0步28人日，GO后产品实现128人日。14天线上验证至少14个连续自然日，生产采集稳定观察另需7自然日；两者不能相互替代。观察期间人工投入计入对应任务，机器等待不伪装为人日，可安排不违反依赖的文档/访谈；实际日历排期由负责人结合批准时间重算。CONDITIONAL_GO至少追加原稿要求的7天复验。
