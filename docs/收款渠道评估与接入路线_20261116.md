核查日期2026-11-16。用户实际情况：个人开发者，有护照、香港银行卡及Wise；已有Creem账户但仅注册/部分审核，未真实收款提现；有中国PayPal账户，未接网站。香港身份证、BRN、香港/海外公司和实际税务居民身份未确认，不能由银行卡或界面语言推定。当前未登录任何支付后台、提交申请、发送消息、绑定银行或发起交易。

用户要求Stripe纳入接入需求，愿比较Dodo等适用渠道。本文是官方资料核查与推荐；不等于渠道批准、产品审批或首发选型签署。国家支持、个人KYC、SoldBench产品审核、商业收款权限和提现能力分别验证。GetPaid Atlas用作线索，关键依据回到各家官方说明。

2026-11-16后续决定覆盖：用户已选定Stripe主支付、PayPal补充接入，Creem/Dodo备用资格核验。以下首次比较和建议保留研究沿革，当前开发按 [Stripe与PayPal接入规格](Stripe与PayPal接入规格.md) 执行；旧候选优先级和“未覆盖Stripe/PayPal契约”描述不再代表当前状态。

## 1. 首次建议选择路径（已由用户决定覆盖）

优先并行核验Dodo与已有Creem。若更看重大陆个人＋本人香港银行卡收款路径，Dodo官方文字与条件更贴合；若Creem可通过本产品审核、接受其个人支付宝结算路径且实际综合费用合适，可复用现有账户。最终仅用获批且完成完整验证的通道首发，不以注册先后替代比较。

Stripe作为用户明确要求的后续接入项，先核对合法主体与身份资格，不能因为暂无资格就从路线中删除，也不能先对外承诺已可用。Paddle保留备选；中国PayPal作为可单独评估的补充收款方式，暂不因“已有账户”直接增加一套支付实现。

## 2. 官方资料与适用性

### Dodo Payments

官方支持Individual类型，中国列在商家准入清单；个人依据核验证件签发国判定。资料链包括产品信息、个人身份和银行审核，实际收款和提现启用还要分别确认。[商家国家](https://docs.dodopayments.com/miscellaneous/accepted-countries-and-territories)、[审核](https://docs.dodopayments.com/miscellaneous/verification-process)

官方允许本人同名的跨国收款银行账户，因此香港银行卡值得优先核查；未找到可据以保证用户Wise账户适用的明确条件。可用币种/转账方式依账户审批。美元默认提现门槛100、可设最低50，低于1000的标准提现费5美元；另有SWIFT/换汇/收款行费用可能。不得把这些概括成“提现免费”。[提现与账户规则](https://docs.dodopayments.com/features/payouts/payout-structure)

公开费率为美国本土卡/钱包4%＋$0.40，国际支付加1.5%，订阅等加0.5%；其他方式另有费率。中国商家身份本身不代表每单都按“美国本土”费率，实际按支付渠道/卡/地区及合同核算。[定价](https://dodopayments.com/pricing)

### Creem

商家支持列表包含中国。中国结算说明区分个人支付宝与企业当地银行；同名香港卡或Wise能否用于用户这个中国个人账户，需取得具体账户确认，不能从“支持香港商家”推导出来。用户现有账户仍属部分审核、未验证可收款/提现。[国家支持](https://docs.creem.io/merchant-of-record/supported-countries)

公开交易费率3.9%＋$0.40；银行出款页另列最低7美元/欧元或1%取高、最低50美元/欧元及每月1/15日的出款窗口。中国个人支付宝的具体适用费率/额度须按账户确认，不把银行费率自动套到支付宝。[交易费率](https://www.creem.io/pricing)、[结算说明](https://docs.creem.io/merchant-of-record/finance/payouts)

### Paddle

官方有个人/sole trader路径，其商业核验步骤与公司不同；中国不在其当前供应商不支持清单中。作为MoR备选值得申请评估，不保证SoldBench通过，不能把个人经营者的条件混成香港Stripe条件。[身份审核](https://www.paddle.com/help/start/account-verification/what-is-account-verification)、[国家范围](https://www.paddle.com/help/start/intro-to-paddle/which-countries-are-supported-by-paddle)

公开标准价5%＋$0.50，实际附加服务、出款/换汇和商务条件另核。[官方定价](https://www.paddle.com/pricing)

### Stripe

Stripe香港官方明确：个人类型不接受非香港身份证号码；没有HKID但有BRN时可选Sole Proprietorship，代表香港业务的申请人可以另用政府签发身份证件。故“护照＋香港卡＋Wise”本身不足以确认开户资格。是否已有HKID、BRN或真实可用实体须查事实；不为开户改报居住地或借用他人账户。[香港资格](https://support.stripe.com/questions/requirements-for-hong-kong-based-businesses)、[跨国开户要求](https://support.stripe.com/questions/requirements-to-open-a-stripe-account-in-another-country)

规划按Stripe Payments/Billing直接收款理解，需自行落实销售主体、税费、发票和退款责任；不把它自动当成与Creem/Dodo相同的MoR方案。其他Stripe产品要另查准入。用户要求必须接入已登记，但首发还是后续取决于真实资格、审批和相应排期。

### 中国PayPal账户

中国账户有提现至香港银行的官方路径。帮助页说明≥1000港元的香港提现不收该笔提现手续费；若将USD换为HKD，仍可能发生汇兑成本。大陆美元电汇标准费用表列35美元/笔，不应据此断言所有香港提现也收35美元。[官方提现说明](https://www.paypal.com/c2/cshelp/article/如何从我的PayPal账户提取资金？-help394)

被核查的中国跨境商家费率页列国际商业收款4.4%＋固定费（USD为0.30）、币种兑换另外计费；该页明确存在不适用的中国账户协议类别。须按用户后台协议、提现预览/汇率和实际账户报价确认，不能照搬海外或香港PayPal费表。[商家费表](https://www.paypal.com/c2/business/paypal-business-fees)

网站订阅技术上有官方集成方案，前提包括已启用Subscriptions的Business账户；现有“中国账户”不能证明已有此能力。仅购买者能支付PayPal、MoR checkout里出现PayPal、用户直连自己的PayPal收款，是三件不同的事。[订阅接入](https://developer.paypal.com/subscriptions/integrate/v6)

## 5. 接入实施边界

采用薄provider适配器，复用现有账本、grant、退款和owner规则。首发实现选中且获批的通道；其他商户申请与技术调研可以并行。Stripe列为明确后续接入需求，资格满足后另立具体工作包/人日，原TASK-029的6人日不能声称已包含所有渠道。

| 事件/动作 | 统一要求 |
|---|---|
| Checkout | 服务端根据已签收offer映射provider price/product，不接前端自报金额/额度；记录provider、环境、merchant、订单和owner |
| Webhook | 每家单独验证原始body/签名；环境密钥隔离，先持久化再确认；不拿Dodo验证器处理Creem/Stripe |
| 支付与周期 | 每个provider支付/周期唯一入账；周期和credit按原业务规则，不把渠道钱包/meters当第二套事实源 |
| 重复/乱序 | 成功回跳不发额度；checkout、订阅激活和周期付款重叠不多grant，持久化去重并向渠道对账 |
| 取消/退款/争议 | 回原渠道处理，既有ledger不改写；保留使用量/撤权/补偿/退款的关联 |
| 加入Stripe或迁移 | 旧订阅仍归原provider，用户不得被自动再次订阅；明确切换周期/未用额度/退款和税务责任，不自动故障切扣另一渠道 |

Creem使用`creem-signature`核验raw body，官方建议订阅权益以`subscription.paid`为付款依据，`subscription.active`作状态同步，避免同时重复grant。[Creem webhook](https://docs.creem.io/code/webhooks)

Dodo按官方webhook协议；Stripe通过官方库核验raw body和`Stripe-Signature`及时间窗。[Dodo webhook](https://docs.dodopayments.com/developer-resources/webhooks)、[Stripe webhook](https://docs.stripe.com/webhooks)

**明确契约缺口**：当前OpenAPI 1.2.0的provider枚举和webhook仍只有Paddle/Dodo，这是既有设计快照，不代表已覆盖Creem/Stripe/PayPal。选型和资格确定后，TASK-002/029必须先同步原稿、API-28、provider DTO枚举、目标webhook签名/事件/fixture与AT-037/038/040，再实现对应适配器；共享SQL的provider文本列不需要为了候选列表预先迁移。当前不虚构已完成这些接入或冻结未获批的渠道接口。

## 6. 成本和最终决策

先验证稳定、足量、可核验供数，再按SoldBench实测完整成本、目标毛利、客户支付意愿及同口径竞品价决定套餐。截图$0.01仅参考；现有$9/$29/$10及额度同属候选。统计每笔交易费、国际/订阅附加、付款方式、提现批次费、换汇/银行费、退款争议、保留款及资金周转；保留款是暂时不可用资金，不直接记为费用。

最终选型以账户审核结果、产品接受范围、实际到账与全成本对照签收；不会仅因基础手续费低、已注册、支持中国或别人用过就认定最适合。
