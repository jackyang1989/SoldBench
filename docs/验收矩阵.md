## 3. 环境与证据清单

每次验收记录：版本/commit或源码hash、启动入口和PID/容器、脱敏DB名/schema迁移、配置版本、source_clearance引用、engine/cleaner/parser/billing版本、固定或真实时钟、测试用户类型、实际query/job/payment ID的脱敏值、命令和退出码、PASS/FAIL/EXPECTED_BLOCKED/NOT_RUN、截图/日志相对路径及hash、复核人。

浏览器至少1440×900、768×1024、390×844；补320px布局检查。按真实点击等待异步保存/响应后截图，人工检查字段/按钮/统计/错误/焦点/滚动；“有截图文件”不代表视觉正确。无实际浏览器不得写UI通过。

## 4. 判定纪律

一个用例因环境缺失无法执行就记NOT_RUN或BLOCKED；预期禁止必须验证后端真实拒绝，不能只截灰色按钮。修复后复测受影响用例和主流程，不把全量次数当功能完整证明。原始失败证据保留并附修复版本，任何仍可复现的主线缺陷阻断对应阶段。
