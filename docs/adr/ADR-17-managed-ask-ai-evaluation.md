# ADR-17 · 托管生成式扩展（Ask AI）专项评估与决策记录（TASK-062 / AT-081）

- **日期**：2026-11-24
- **关联任务与验收**：TASK-062、AT-081、DEC-15、DEC-18
- **结论状态**：`DEFERRED / NOT_ADOPTED_FOR_LAUNCH`（首发不上线托管生成式 Ask AI，保留既有确定性文档搜索与工单支持入口，详见 [DEC-15](../决策登记.md)）

> 2026-11-25 续记。DEC-19 将站内产品问答独立列为首发 TASK-063。下文为 11 月 24 日对托管模型的评估记录。“文档与 MCP 已覆盖站内问答”的范围判断由 DEC-19 修订。生成式扩展进入 TASK-064 候选工程，供应商、预算和数据处理仍待专项审批。[Ask 实施规格](<../Ask SoldBench AI 实施规格.md>)

## 1. 评估范围

在原型基准文件 `SoldBench Prototype.html` 中出现过面向研究辅助的 `Ask` 交互入口。依照 `DEC-15` 与 `TASK-062` 要求，团队对是否在首发或近期版本上线“托管大语言模型生成式 Ask 问答扩展（Hosted Generative Ask AI）”进行专项技术、成本、可核验性与数据源合规评估。

## 2. 四项评估维度结论

| 评估维度 | 事实约束与风险 | 决策结论 |
|---|---|---|
| 确定性统计与“未知绝不猜测”不变量（AGENTS.md §5 / ADR-12） | LLM 自然语言摘要存在数值幻觉风险（如把 `median=null` 的 `<8` 样本推断出估值区间、将未知运费或未知 Best Offer 近似成 `0`、跨币种估算汇总），与 SoldBench 整数分 Type 7 精确统计及严格可审计证据相冲突。 | 必须保证大模型零参与权威定价/统计结论生成。 |
| 单位经济与推理边际成本（DEC-07） | 在尚未完成 14 日真实采集成本与套餐留存/荒废率（breakage）测算前，按高频互动会话计费的外部大模型 Token 成本缺乏上限保护，极易击穿低单价订阅毛利。 | 无真实单位经济实测前不引入无上限 AI 推理支出。 |
| 上游来源许可与输出再分发边界（DEC-05） | 将受来源权限保护的逐条成交标题、图片描述或卖家属性送入第三方托管 LLM API 涉及额外数据处理条款与禁止训练/留存合同审查。 | 未完成模型供应商零留存协议及来源书面允许前不得外传受权文本。 |
| 首发替代方案完备性（DEC-15 / TASK-034 / TASK-037） | 现行公开及账户帮助、全文检索文档站（`/docs` EN + `zh-CN`）、`llms.txt`、Hosted MCP（`sold_search` / `sold_stats`）与工单支持系统已经完全覆盖用户查帮助与 AI Agent 原生集成诉求。 | 现行确定性文档 + MCP 工具链可完美满足首发与用户自定义 AI 客户对接，无需官方自担大模型推理成本。 |

## 3. 正式决定（不实施说明与未来单独立项条件）

1. **当前决定**：**暂不采纳（DEFERRED）托管生成式 Ask AI**。首发 `TASK-062` 只完成促销活动（Promo）、版本化报价（Offer Versioning）与本项评估档案，**不**在代码库引入外部 LLM SDK、提示词服务或生成式问答端点。客户侧自带 AI 代理仍统一通过既有 MCP（`sold_search` / `sold_stats`）受权限与账本保护访问结构化数据。
2. **未来若批准采用时的独立范围与估算前置**：
   - 先由创始人及法务签署第三方 LLM 数据处理/零留存合规评审与独立 AI 算力预算上限（单独配额/收费开关）；
   - 单列 **12 人日**独立实施任务，构建**严格检索增强 + 数值只读引用校验器**（禁止模型输出任何未经当前 `query_results` / `calc_inputs` 核验的金额，遇 `<8` 或未知字段强制退回确定性 `null` 提示）、Per-User Token 限流与专属 **AT（幻觉拦截、撤权即时阻断、费用隔离）** 后方能启动编码。
