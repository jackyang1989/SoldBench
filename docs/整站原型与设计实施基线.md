## 1. 设计实施规则

- 从原型提取共享 token、React 组件和布局，先复现原型的首页、桌面研究页、文档页、账户页和运营页，再用同一套组件补缺失页面。新增页面仍需逐页验收，关键布局、视觉层级或交互变更交用户确认。
- 保留暖底色 `#FBFAF7`、白卡片 `#FFFFFF`、深色正文 `#0C1116`、主操作陶橙 `#C2461E`、深色代码区 `#0B1220`，以及原型的状态配色、边距、分区、边框与表格密度。营销标题使用 Source Serif 4 与对应中文衬线回退，界面使用 Inter 与对应中文无衬线回退，代码与标识用等宽。默认容器 1280px，宽屏按原型逐级扩展。标准控件 40px，同排字段 44px。
- 公开站沿用主导航和内容容器，文档沿用左导航、正文和目录布局，账户及运营沿用流式侧栏、KPI 卡、筛选工具条、可滚动数据表与详情抽屉。数值表头与单元格对齐，窄屏保留行列语义和可操作入口。复用表单、表格、分页、状态徽标、抽屉、确认对话框、空态及反馈。状态同时用文字表达，支持键盘、焦点恢复、读屏和减少动效。
- 以原型的各业务页面为设计参考，按现行 React SSR/Hono 路由、语言与权限架构实现。生产地址按已冻结路由和部署目标；原型 `#/...` 仅用于定位设计。页面直达、刷新、返回、切语言均须复验。共用的界面标签属于翻译目录；由运营维护的内容从已发布配置渲染。

## 3. 演示值的替换清单

| 原型示意 | 实施的数据源及检查 |
|---|---|
| `DATASETS`、模拟成交流、主图、时间戳、报价、价格可信度、指标计数与本地 `computeStats` | 读当前授权的公开投影或私有权威快照。完整重算走共享 core，统计按整数分、Type 7 和两端 floor(5%×n)，质量总分保持 null。未知议价和运费依领域规则。对比 121/64/58、0/7/8/29/30 和缺图情形；生产数据缺失时解释无数据或未知，公开页不回填原型数字 |
| `CMS_DEFAULTS`、`sb_cms_v1`、样例套餐/年付/高用量档、素材与文案 | 内容读取服务端生效版本；金额、额度及限速只引用已签收且实际生效的报价，调用 checkout 时同一报价版本。可用市场、健康、覆盖来自真实投影。演示套餐、发布记录、竞品结论、法律和联系方式在真实证据签收前保持预览 |
| 本地快照、模拟账号/key/账单、定时器 Playground、模拟支持、模拟管理审批/恢复 | 调用相应的真实本机或已授权服务，逐请求校验权限，只有服务端提交成功后呈现成功。失败有原任务重试、补充证据或明确受限状态。真实账务、用户与凭据不出现在原型数据或团队共享截图 |
| 说明性或测试性样本 | 允许在明确隔离的合成示范、文档示例或预览中保留，并在英中界面标记。正式页面从原型切换时逐页面登记替换源及剩余空态，保留渲染截屏、request ID、发布版本和脱敏数据差异 |

## 4. 视觉与行为签收

开发前对照原型做页面/组件清单，标记复用、接线、补绘、待协议、后续包。提交实际构建在 320/390/768/1440px 的同视口对照，补宽屏运营数据表；两语分别检查空态、加载、失败、成功、降级与撤权。用可见操作完成一次查询、领取和复取，核对金额和原快照。运营签收再用两个独立会话操作发布、已发布版本复用和回滚。签收保留原型 hash、产品提交、viewport、语言、角色、配置版本及备注，关联 AT-035/043/052/055。[配置发布契约](运营后端实施契约.md#运营中心与前台可配置发布2026-11-19)
