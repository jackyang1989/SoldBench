# 功能与页面规格

版本：实施补充1.1，2026-11-16；异步交付、额度、时间和身份按ADR-12。产品范围以原稿 §1/2 为准；本文按ADR-13允许完整离线开发，真实接入/发布仍须对应GO，当前不是已上线能力。客户界面首发英语＋简体中文，内部开发文档中文；遵循 [多语言与商业交付补充规格](多语言与商业交付补充规格.md)，语言切换不改变站点、USD、查询身份和收费。每个 PAGE 必须真实接入服务端；前置不足时显示原因及恢复动作，不用演示值补成功。

## 1. 用户与权限

产品目标客户包括以下六类，客户画像不等于权限角色。同一人或企业可有多种使用场景，权限仍由账户、owner和scope决定。

| 客户 | 核心问题 | 主要交付入口与首发价值 |
|---|---|---|
| 个人卖家 | 自己的商品最近卖多少钱、哪些记录值得参考 | 网页查价、属性筛选、价格区间、成交明细及时间/样本解释 |
| 收藏品交易商 | 版本/评级/成色不同是否可比，收购和出售参考价依据是什么 | 网页研究、严格匹配、单条证据、排除原因与本地重算 |
| 二手商家 | 不同型号和成色如何定价、重复查询如何回看 | 网页查价与历史结果；有自有系统时使用API集成 |
| 开发者 | 如何在自己的工具中接入可信成交数据 | REST、完整契约、示例、密钥和用量；Agent可使用MCP |
| SaaS 企业 | 如何把成交研究能力接入产品，稳定控制错误及费用 | API/MCP、owner授权、可复取结果、版本、幂等与计量 |
| 专业数据使用者 | 样本和价格口径能否解释、复算及用于研究 | 网页/API读取获准明细与完整计算输入，检查时间、覆盖和排除依据 |

网页应支持用户无需创建API key或编写代码完成注册、查价、理解结果、研究明细和回看历史。匿名缓存限制与注册后的查询能力分别说明。SaaS集成依来源实际允许的商业使用范围交付；单结果JSON/CSV导出纳入首发；批量上传/多年历史已按DEC-13进入后续任务，团队权限不在本次范围。计划范围与实际可用能力须分开。

| 主体 | 可以操作 | 明确禁止 |
|---|---|---|
| 访客 | 首页缓存查询、方法/定价/文档/状态、允许公开内容、有效分享 | 发起实时采集、账户记录、余额与 key |
| 已登录未验证用户 | 验证/退出、修改未验证邮箱的受控流程 | 获得查询免费月额、创建正式 key、付费消费 |
| 已验证用户 | 自己的查询、任务、余额、订阅、key、分享和删除请求 | 他人资源、后台、来源原文秘密 |
| API key | scopes 允许的 sold:read、jobs:read、usage:read；owner 仍是用户 | 创建 key、改账单、访问后台、绕过邮箱停用 |
| 支持人员 support | 脱敏用户状态、请求 ID、只读计费与工单 | 查看 key 明文、写钱包、批准来源、查看未经授权原文 |
| 管理员 admin | MFA 后停来源/重排允许任务、审计查询；经相应授权处理补偿 | 无痕改账本、擅自批准商业 GO、扩大来源权限 |
| Collector/Worker | 最小服务角色、限定来源和内部命令 | 客户会话操作、修改商业授权、直接绕过结算服务 |

仅隐藏按钮不算权限控制。私有对象越权返回 404 防枚举；已认证但缺操作 scope 返回 403；未认证为 401。分享 capability 只用于该分享快照，不转换成 owner 身份。

## 4. 核心用户路径

### U1 访客首次使用

打开首页→输入或选真实缓存例子→查询→结果说明。缓存未命中不创建 Collector 任务；次数耗尽显示次日恢复时间和注册入口。匿名结果绑定匿名 session capability，不能允许凭 query UUID 公共读取任意用户结果。匿名计数与 credits 分开，不显示“扣 1 credit”。

### U2 开发者调用

注册→真实邮件验证→创建 key 一次复制→REST 查询→200 或202→任务状态→领取/复取结果→usage 对账。余额不足不会把已购结果锁死；参数错误不会扣费。计算完成显示“Claim result”，显式POST claim后返回结果；轮询和重复复取0credit。

### U3 卖家、交易商、商家与专业用户的可信价格研究

无需API key，从网页表单提交强属性→查看统计和排除诊断→查看单条证据摘要→改 price_basis 作为新查询→手工剔除后显示 Your adjusted view→恢复原始结果。UI 显示“基于完整 N 条”或“仅当前已加载 N 条”，不混淆。服务端原快照不可修改；本地重算不计费，也不进入正式 API/SEO/分享权威结果。

### U4 订阅与退款

选择获批套餐→服务端创建 Checkout→渠道付款→回跳 pending→核验 webhook/主动对账→发放唯一周期桶→用量消费→取消期末→保留购买桶。现金退款和 query credit refund 分别显示。离线退款规则按ADR-12/DEC-02，真实现金政策及渠道签收仍在发布门，不能自己发明 7 天退款承诺。

### U5 断源及恢复

停止 Collector→账户/账单/key 仍可操作→fresh 合法缓存正常→>24h 未同意 stale 则明确无当前数据→同意后 ≤72h 免费→>72h 当前查询503→有权的已购历史只读→权限撤销停止分发→恢复探针/回填/质量门→恢复 fresh。不能后台刷新 old data_as_of。

### U6 用户/来源删除

用户重新认证申请→立即撤销会话/key及分享→后台执行允许删除与法定保留脱敏→状态可查。来源权利撤销独立处理全用户派生数据；既有账务事实保留但不保留被禁止的商品内容。备份恢复须先重放删除与撤销，再对外开放。
