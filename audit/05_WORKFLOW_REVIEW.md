基线 808b987。空浏览器在英中首页均可输入但提交到 404。账户入口未完成。业务 E2E 从此阻断。独立 HTTP/PG16 测试提供后端证据，详见 [15](15_FINAL_VERIFICATION_REPORT.md)。以下频率和愿付仅作待访谈假设。

| 客群 | 目的、频率与愿付假设 | 现行主路径与断点 | 提议路径、收益和模块 |
|---|---|---|---|
| 个人卖家 | 上架/收购前偶发，倾向免费或小额包 | 首页点输入→输入→点提交，2 次鼠标操作后 404，无价格结果；点 Research/Account 也失效 | 首页直接进入匿名聚合结果，缓存未命中保留输入与显式注册。先价格区间/样本口径，再成交表、授权链接和详情。TASK-031/032，减少跳页 |
| 收藏品商家 | 每批收货重复用，愿为正确版本、评级、成色和可信证据付费 | 后端有强属性和详情，网页无筛选、明细、主图、排除/本地重算 | 型号/评级/等级/版本显式条件，同款与不可证分组。证据抽屉独立，保留日期/价格证据；低样本给放宽条件或保持历史选择。TASK-019/032 |
| 二手商家 | 每日或每批反复，同型号不同成色，关注节省时间 | 后端可复取与单结果导出，网页没有历史和文件入口 | 入口统一到 /research 与历史。复取标时间和原权威口径，单结果下载可重试。批量在 TASK-045 后续，首发用历史复用。TASK-032/033 |
| 开发者 | 集成初期密集，之后按自动任务；愿为可靠量/文档付费 | /docs 有双语 Markdown，脚本可过本机，无法可见注册→key→Playground；属性及取消协议偏差 | 空账户引导出一次性 key，清晰 scope/轮换/撤销，三种真实示例，展现 request_id、headers、余额、Retry-After 及查费。TASK-023/024/028/033/037 |
| SaaS 企业 | 持续和峰值用量，核 SLA、数据使用权和成本 | 模拟 owner 和幂等成立，真实跨环境、账单、数据用途待证 | 明确再分发和用途，固定键重试与 retry budget；核租户用量/错误/版本、授权沙盒。团队权限仍按原策略。TASK-025/028/029/037/042 |
| 专业数据使用者 | 批次研究，按可复现与覆盖需求选用 | 完整候选和导出有离线证据，日精度投影和使用界面缺 | 权威结果和本地调整并列，显示完整输入/数据版本/口径/可获字段、无权导出拒绝。TASK-020/028/032 |

## 网页路径与恢复

当前首页到结果的有效路径未连通。建议匿名用户填 q，筛选可选且保留状态，提交后直接进入聚合摘要或明确未命中。结果首屏显示区间、样本级别、时间和价格口径。展开可比/可核验/排除分母。仅有证据的标题及图片可外链已登记的原始成交页，详情有独立可访问控件。缺字段、来源链接失效或撤销时仍按权限提供历史证据或显示受控状态。剔除重算以完整计算输入、快照和版本验证为前提，撤销剔除可恢复。保存使用已有历史快照；单结果导出可重试，无新扣费。收藏条件和批量功能按后续任务执行。

免费用户在首页看到匿名日限及未命中含义。完成验证后可在 Overview 看余额、有效期和消费原因。查询排队后浏览 Poll 不计费，领取前公开扣费条件，断线用同幂等键，已交付可免费查看。对无样本、缺属性、503、429、余额不足、超时和分享失权分别保留明确文案与下一步，避免浏览器显示裸 JSON。双语不切换币种、owner 或费用。

## 六条任务的交付定义

以下为可供非实现者复跑的任务脚本草案。浏览器仅完成首页、语言切换、查价及账户入口的失败复现。API 的离线结果不能替代这些脚本的可见完成记录。

| 角色与输入 | 输入、收费和状态转换 | 明确完成条件及最小维护范围 |
|---|---|---|
| 偶发上架的个人卖家，某一型号、成色、近 30 天 | 首页保留一次提交，匿名只看允许的缓存聚合；无命中时解释“未缓存”，不创建作业；限额恢复时间在原页。核验注册后可见自己的额度 | 摘要解释费项、样本级别和最后有效时间。由结果点一条合格样本核对，缺图行仍在。AT-034/035/056。只计算提交动作是 1 次；算入鼠标聚焦为 2 次，当前两种算法都到 404 |
| 收藏者，明确版别、评级公司及等级 | 选择已开放类目的强属性，看 applied filters 与匹配样本。不确定版本、未知 Best Offer、缺所需运费可从排除诊断逐行追溯；低样本不出中位数 | 恢复一条本地剔除后，权威结果、账本和他人视图均无变化；历史研究标日期和口径。用 fixture 验证流程，品类可比性仍需独立金标。AT-011/012/025/058 |
| 二手商家，同型号商品重复来货 | 从历史打开已有交付免费；显式改条件才发新查询；允许单查询导出 JSON/CSV（权威或调整）。下载中断可在仍有权时重试 | 获取同一 query_id、候选版本和价格基础；调整导出标注范围。首发重用历史/导出，避免把批量 CSV 与未来收藏当作已交付。AT-024/059 |
| 开发者，从未注册 | 页面注册、一次核验、选 scope、创建并复制一次性 key、在私有环境配置，按语言示例发请求；展示 202、status、显式 claim、免费复取 | Logs 用 request_id 查到状态和相应 charge，返回数量与限额不改变单查询计费；演练旧 key 撤销、权限不足、429 有界退避。AT-033/045/050/057 |
| SaaS 集成方，需要嵌入研究结果 | 先核对展示与 API 再分发用途，按 owner 独立设置凭证与预算；无可分发权限时返回不可用，不能读旧缓存填补。约定渠道对账；恢复时使用同一作业/幂等引用 | 用两个 owner 验证隔离，从网络断线恢复后完成一次领取。对勘业务订单、周期 grant、订阅取消及 usage。商业授权与上线 SLA 均待签收。AT-026/029/038/058 |
| 专业研究者，需要复算和引证 | 取权威快照、完整输入（若有权）、诊断、分组及统计版本；保留 as_of/data_as_of。受限输入只能表述当前子集 | 同快照算出相同数值；50 展示 vs 58 输入、缺运费、日精度、组内 n<8 均可复核；被撤权限阻止重新导出和分享。AT-014/015/025/044/074/075 |

保存研究的首发实现边界是 owner 历史快照；命名文件夹、自动提醒、多商品横向比较及库存批量估值需要另行验证复购价值。已交易用户即使无余额也应能看已交付历史、对账、取消续费。返回已交付结果时复查授权；旧版链接失效可展示原有可用证据，不悄悄为用户发新查询。运营复盘按来源停用与权利撤回分流：前者判断当前许可和时效；后者先拒读并依既有清理流程恢复。[页面卡与工作流](../docs/功能与页面规格.md) · [研究交付契约](../docs/查询账本与交付实施契约.md) · [套餐与现金回调](../docs/Stripe与PayPal接入规格.md)
