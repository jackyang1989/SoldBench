# 第 0 步证据模板

复制对应小节到实际任务产物并填写，空白/占位不算证据。只存脱敏信息及受控原件引用。

## 来源准入卡

- 来源ID / marketplace / 入口 / 域名 / provider：
- 目标主体与适用地区/协议版本/获取日期：
- 允许方法（approved_http/approved_browser/offline_fixture）：
- 是否允许自动获取/原文存储/派生存储/统计公开/逐条公开/API再分发/分享：逐项yes/no/unknown。
- 字段许可、保留期限、历史窗口、公开地域/用途与删除义务：
- 请求频率/并发/页数/流量限制及停止信号：
- 平台要求的书面许可引用/hash/有效期：
- 法律审核引用、创始人确认、独立复核：
- 当前状态及为什么；下一步责任人：

任一必需项unknown时相应能力关闭；不能把“网页可见”填入允许API再分发。

## 每日运行记录

- 日期、时区、实际运行时段、代码/配置/语料hash：
- mode=offline_fixture/approved_http/approved_browser：
- source_clearance引用及有效性复核：
- 计划/实际请求分母、首次/最终成功、失败分类、每类指标：
- 延迟P50/P95、字段完整性、去重、样本资格、实际价格核验：
- 网络/CPU/存储/页数/重试/人工维护及成本：
- 原始日志/受控证据引用、意外中断、是否影响连续14天：
- 操作者/复核者及下一日行动：

## 访谈记录（脱敏）

- 编号/日期/角色及实际业务：
- 当前工具、每月成功查询量、失败代价、最大预算、关键属性和历史需求：
- 对比同一查询样本的具体反馈：
- 是否愿付费：金额/用量/启动条件/试点期限/可核验承诺引用，区分礼貌意向：
- 许可取得方式及信息保留范围：

## 独立审查与断源记录

- 审查者是否非实现者、源码/依赖/出口范围：
- 实际停止方式：进程/主机/出口/仅mock，模拟时钟与真实时长分开：
- 0/24/48/72h和边界状态、data_as_of、allow_stale、收费断言：
- 权限撤销后的DB/缓存/分享/页面读链：
- 恢复probe、回填事件计数、charge/ledger对账：
- 第0步只是PoC还是正式全链路、仍未验证事项：
- 命令/退出码/附件hash/结论：
