# 客户访谈执行准备

TASK-008，2026-11-16。当前完成访谈数为0，记录与付费承诺待真实客户提供。目标10–15位，覆盖个人卖家、收藏品交易商、二手商家、开发者、SaaS企业和专业数据使用者。每位受访者以脱敏ID记录，联系方式和原录音保存在受控资料区。

## 同一份核心问题

1. 请展示最近一次查价、收货估价或批量定价的实际任务，记录从输入到决策的步骤、工具、耗时及卡点。
2. 过去一个月大约研究多少商品、发起多少不同查询、复查多少次？其中网页查价、程序调用和专业研究各占多少？记录可核实的范围及估计依据。
3. 型号、版本、成色、评级、配件、运费、议价实际价及历史窗口中，哪些差异会让你拒绝一个可比成交？什么情况下宁可不出价？
4. 请比较同一查询下的成交明细、价格分布和排除理由。哪些证据足以支持决策，哪些必须人工核对？避免先展示预设“正确答案”。
5. 最近30天和90天能解决哪些任务？超过90天解决什么具体问题？历史样本稀疏、价格过时及覆盖未知时如何处理？
6. 采集暂时中断时，你能接受多旧的数据、怎样的提示和恢复时间？是否愿意查看明确免费且标时点的陈旧快照？
7. 目前为这些工具花多少钱？预算由谁批准？如果迁移，必须保留哪些数据、工作流或集成？
8. 针对刚才完成的任务，用实际用量分别讨论候选套餐和按量额度，记录最高愿付价、购买条件和拒绝理由。价格随机顺序展示，避免锚定单一$29方案。

## 各类客户追问

| 客户 | 具体追问 |
|---|---|
| 个人卖家 | 单件上架和收购前查价频率、手机操作、可接受的每月预算 |
| 收藏品交易商 | 评级机构/等级/版本/语言的强约束、低流通品历史、证据复核 |
| 二手商家 | 收货估价到库存决策流程、同型号成色、店员使用和人工审核 |
| 开发者 | 实际请求/并发/延迟、异步领取、错误恢复、凭证和集成成本 |
| SaaS企业 | 下游展示/再分发范围、租户用量、成本预算、采购及支持要求 |
| 专业数据使用者 | 可复现快照、覆盖/偏差、完整候选和字段、历史研究方法 |

## 脱敏记录模板

每次记录受访ID、客户类型、日期、同意记录方式、实际任务/类目、现用工具、真实或估计用量、网页/API需求、预算范围、愿付价、迁移阻碍、购买条件、可回访状态及受控证据引用。对“有兴趣”“愿试用”和“明确预算购买承诺”分别保存原话。目标至少3份明确付费承诺，是否成立由负责人复核。

新功能建议回填原范围评审。访谈中出现批量、团队或第二平台需求时记录频率和价值，按后续版本决定。问卷完成后由创始人安排实际邀约与资料授权。
