# 第 0 步断源模拟

2026-11-16，TASK-006。逻辑时钟注入 0/24/48/72 小时和边界后 1 毫秒，时区 UTC。状态来源为本地合成分页回放提交的保守覆盖水位。运行 `npm --prefix step0/collector-poc test` 可复现。

| 注入时间 | 候选状态 | 当前查询读取 | 潜在标准查询额度 |
|---|---|---|---|
| 0h、24h | fresh | 当前权利允许且有快照可读 | 合格样本至少 8 条时 1，否则 0 |
| 24h 后 1ms、48h、72h | stale_acceptable | 显式同意后可读 | 0 |
| 72h 后 1ms | expired | 当前价不可读 | 0 |
| 任意时点权利撤销/未准入 | forbidden | 拒绝读取 | 0 |
| 冷缓存/无覆盖水位 | unknown | 不可读 | 0 |

测试证明读取决策期间 FixtureTransport 派发次数不增加。恢复时重复来源事件保留同一事件数，新增观察证据。已有 collector 用例覆盖失败水位保留、重启回放、预算和熔断。

`potentialCredits` 仅表示单次决策的候选规则，真实账本尚待开发，重复领取与账户隔离按后续资金工作包验证。58 条样本数在集成模拟中显式注入，Collector 演示事件本身只验证身份和水位。fresh/stale 阈值为待商业签收的候选。

验证范围为离线 TypeScript PoC，使用单写者临时文件和合成权利状态。真实 72 小时停机、Web/API/账户/支付管理可用性、Redis/PG 故障及非实现者复核列入 TASK-040 的实际集成验收。线上持续时间和生产 SLA 仍待实测。
